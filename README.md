# VidScoop（视频捞取器）

> 浏览器里看到好视频，点一下，它变成你笔记库里的一篇 Markdown。
> 全程免费 API，零服务器，数据只在你自己电脑上。

**当前状态：v0.1，能用，但别期待精致。**

## 它是什么

一个 Chrome/Edge 扩展 + 本地 Python 助手：

```
你在视频页点悬浮按钮
   ↓
本地助手接管：yt-dlp 抓取 → 语音转写 → AI 整理 → AI 摘要
   ↓
一篇带 frontmatter 的 Markdown 笔记，写进你指定的文件夹
```

- **支持平台**：B站、YouTube
- **输出**：纯 Markdown 文件 + 自定义保存路径。Obsidian 用户直接可用，Notion/VS Code/文件夹党同样能用，**不绑定任何笔记软件**
- **成本**：全链路免费额度，见下文

## 为什么强调"全免费"

同类工具几乎都要求你自备付费 ASR/LLM key（阿里百炼、豆包、OpenAI…）。本项目实测跑通了一条**零成本链路**，全部使用厂商免费额度：

| 环节 | 模型 | 免费情况 | 实测速度 |
|---|---|---|---|
| 语音转写 | 硅基流动 SenseVoiceSmall | 永久免费 | 20 分钟音频约 25 秒 |
| 逐字稿整理 | Groq gpt-oss-120b | 免费额度（14400 次/天） | 约 6 秒 / 2800 字 |
| 摘要 | 同上 | 同上 | 约 4 秒 |

> 实测：5500 字的 B站长视频，从点击到笔记落盘 **55 秒**。
> （对比：用智谱 glm-4-flash 做同样的活，需要 3 分钟——速度差 10 倍，我们替你踩过了。）

## 天下没有免费的午餐（诚实声明）

免费额度的代价，你需要知道：

1. **要自己注册 2-3 个平台拿 key**（约 20 分钟，下文有步骤）
2. 免费档有并发/限流，高峰期偶尔要重试
3. 免费模型质量够用但不如付费旗舰（摘要偶尔平铺直叙）
4. 各家免费政策**随时可能调整**，本项目会跟进，但不承诺

如果你不想折腾：本项目不适合你，用付费 ASR 服务更省心。

## 第一步：获取 API Key（一次性，约 20 分钟）

> **为什么必须自己申请**：这个工具要调转写和 AI 服务，用的是各家厂商的免费额度。免费额度绑定在你自己的账号上，所以必须你自己去注册拿 Key——作者没法替你申请，也没法把自己的给你。

### 1. Groq（必填）

1. 打开 https://console.groq.com/keys
2. 用邮箱或 Google 账号注册（**需要能访问国际网络**）
3. 登录后点 **Create Key**
4. 复制那串以 `gsk_` 开头的字符，**关掉页面后就看不到了，请立刻粘贴保存**

免费额度：每天 14400 次请求，个人用绰绰有余。

### 2. 硅基流动（必填）

1. 打开 https://cloud.siliconflow.cn/account/ak
2. 注册（需要**手机号实名**）
3. 登录后进「API 密钥」页面，点「新建 API 密钥」
4. 复制那串以 `sk-` 开头的字符

免费额度：`SenseVoiceSmall` 转写模型永久免费。

### 3. 智谱（选填）

1. 打开 https://open.bigmodel.cn/
2. 注册后进「API Keys」页面创建
3. 复制 Key

作用：作为备用渠道，Groq 挂了会自动切过来。不填也能用。

## 第二步：配置（两种方式，任选一种）

### 方式 A：配置向导（推荐，新手用这个）

双击 **`配置向导.bat`**，按屏幕提示粘贴 Key 和保存路径，回车即可。

向导会：
- 检查 Key 格式对不对
- 自动生成 `.env` 配置文件
- 验证配置是否可用

**不用手动编辑任何文件。**

### 方式 B：手动编辑（老手用）

1. 把 `.env.example` 复制一份，改名为 `.env`（**注意前面有个点**）
2. 用记事本打开 `.env`，填两个必填项：

```env
GROQ_API_KEY=gsk_你的key
SILICONFLOW_API_KEY=sk-你的key
VAULT_DIR=D:/我的笔记
```

3. 保存

> **常见错误**：
> - 文件名写成 `.env.txt` —— 要确认扩展名是 `.env`
> - Windows 路径用了反斜杠 —— 要写成 `D:/我的笔记` 而不是 `D:\我的笔记`
> - Key 前后带了空格 —— 复制时注意别多选空格


## 第三步：安装（4 个动作，按顺序来）

1. **下载本项目**：页面上方 Code → Download ZIP，解压到任意文件夹

2. **双击 `安装本地助手.bat`** —— 首次会自动创建 Python 环境、装依赖、注册本地助手（约 1-2 分钟，需要联网）

3. **双击 `配置向导.bat`** —— 按提示粘贴两个 Key 和保存路径

4. **加载扩展**：
   - 浏览器打开 `chrome://extensions`
   - 右上角打开「开发者模式」
   - 点「加载已解压的扩展程序」
   - 选择本项目里的 `extension` 文件夹
   - 加载后复制卡片上的 **扩展 ID**（32 位字母）
   - 双击 `绑定扩展ID.bat`，粘贴 ID，回车

> **为什么不上 Chrome 商店**：本项目需要本地 Python 助手配合，商店审核规则对此不友好；且目标用户本就需动手配 key，手动加载不构成额外门槛。
> **注意**：开发者模式加载的扩展，Chrome 会周期性弹确认，点「保持启用」即可。

### 装好了怎么检查

- 浏览器工具栏能看到蓝青色的图标
- B站/YouTube 视频页右侧能看到悬浮按钮
- 点它，按钮开始转圈，几十秒后笔记出现在你的保存目录

**任何一步不对**，先看下面「常见问题」。


## 使用

打开 B站/YouTube 视频页 → 等播放器出现 → 点右下角悬浮按钮 → 等进度走完 → 笔记出现在你的 `VAULT_DIR/00-Clip`。

## 常见问题

- **YouTube 报"IP 被平台判定可疑"**：你当前代理出口 IP 被 YouTube 风控（机房 IP 尤其容易）。换个节点再点。这不是代码能解决的。
- **B站大会员/付费视频**：抓不到，正常。
- **转写没标点、有错字**：AI 整理环节会修，但专有名词（人名/产品名）仍可能错，这是语音识别的固有局限。
- **换了电脑/换了目录**：重新双击一次 `安装本地助手.bat` 和 `绑定扩展ID.bat` 即可。
