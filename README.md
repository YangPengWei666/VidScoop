# VidScoop（视频捞取器）

> 浏览器里看到好视频，点一下，它变成你笔记库里的一篇 Markdown。
> 全程免费 API，零服务器，数据只在你自己电脑上。

**当前状态：v0.1 首发准备中。**

---

## 它是什么

一个 Chrome/Edge 扩展 + 本地 Python 助手：

```
你在视频页点悬浮按钮
   ↓
本地助手接管：yt-dlp 抓取 → 语音转写 → AI 整理 → AI 摘要
   ↓
一篇带 frontmatter 的 Markdown 笔记，写进你指定的文件夹
```

- **支持平台**：B站、YouTube
- **输出**：纯 Markdown 文件 + 自定义保存路径。Obsidian 用户直接可用，Notion/VS Code/文件夹党同样能用，**不绑定任何笔记软件**
- **成本**：全链路免费额度，见下文

## 为什么强调"全免费"

同类工具几乎都要求你自备付费 ASR/LLM key（阿里百炼、豆包、OpenAI…）。本项目实测跑通了一条**零成本链路**，全部使用厂商免费额度：

| 环节 | 模型 | 免费情况 | 实测速度 |
|---|---|---|---|
| 语音转写 | 硅基流动 SenseVoiceSmall | 永久免费 | 20 分钟音频约 25 秒 |
| 逐字稿整理 | Groq gpt-oss-120b | 免费额度（14400 次/天） | 约 6 秒 / 2800 字 |
| 摘要 | 同上 | 同上 | 约 4 秒 |

> 实测：5500 字的 B站长视频，从点击到笔记落盘 **55 秒**。
> （对比：用智谱 glm-4-flash 做同样的活，需要 3 分钟——速度差 10 倍，我们替你踩过了。）

## 天下没有免费的午餐（诚实声明）

免费额度的代价，你需要知道：

1. **要自己注册 2-3 个平台拿 key**（约 20 分钟，下文有步骤）
2. 免费档有并发/限流，高峰期偶尔要重试
3. 免费模型质量够用但不如付费旗舰（摘要偶尔平铺直叙）
4. 各家免费政策**随时可能调整**，本项目会跟进，但不承诺

如果你不想折腾：本项目不适合你，用付费 ASR 服务更省心。

## 第一步：获取 API Key（一次性，约 20 分钟）

| # | 平台 | 拿什么 | 地址 |
|---|---|---|---|
| 1 | **Groq**（必填） | 注册后 Keys 页创建 API Key | console.groq.com |
| 2 | **硅基流动**（必填） | 注册后「API 密钥」页创建 | siliconflow.cn |
| 3 | 智谱（可选） | 开放平台创建 Key，glm-4-flash 免费 | open.bigmodel.cn |

> Groq 是国外服务，需要能访问国际网络。
> 硅基流动注册需要手机号实名，SenseVoice 转写模型在免费列表里。

## 第二步：配置

把 `.env.example` 复制一份改名为 `.env`，用记事本打开，填入：

```env
GROQ_API_KEY=***
SILICONFLOW_API_KEY=***
VAULT_DIR=D:/MyNotes          # 笔记保存路径，随便指哪个文件夹
```

笔记会写进「`VAULT_DIR`/00-Clip/」目录。

## 第三步：安装（5 个动作）

1. **下载本项目**（Code → Download ZIP，解压到任意目录）
2. **双击 `安装本地助手.bat`**——首次会自动建虚拟环境、装依赖，然后注册本地助手
3. **加载扩展**：浏览器打开 `chrome://extensions` → 右上角开「开发者模式」→「加载已解压的扩展程序」→ 选本项目里的 `extension` 文件夹
4. **复制扩展 ID**：加载后扩展卡片上那串 32 位字母
5. **双击 `绑定扩展ID.bat`**，粘贴刚才的 ID，回车

> **为什么不上 Chrome 商店**：本项目需要本地 Python 助手配合，商店审核规则对此不友好；且目标用户本就需动手配 key，手动加载不构成额外门槛。
> **注意**：开发者模式加载的扩展，Chrome 会周期性弹确认，点「保持启用」即可。

## 使用

打开 B站/YouTube 视频页 → 等播放器出现 → 点右下角悬浮按钮 → 等进度走完 → 笔记出现在你的 `VAULT_DIR/00-Clip`。

## 常见问题

- **YouTube 报"IP 被平台判定可疑"**：你当前代理出口 IP 被 YouTube 风控（机房 IP 尤其容易）。换个节点再点。这不是代码能解决的。
- **B站大会员/付费视频**：抓不到，正常。
- **转写没标点、有错字**：AI 整理环节会修，但专有名词（人名/产品名）仍可能错，这是语音识别的固有局限。
- **换了电脑/换了目录**：重新双击一次 `安装本地助手.bat` 和 `绑定扩展ID.bat` 即可。
